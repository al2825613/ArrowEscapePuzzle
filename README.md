# Arrow Escape Puzzle

لعبة ألغاز محمولة احترافية مبنية باستخدام Flutter و Flame Engine.

## الميزات

- **طريقة لعب جذابة:** لعبة ألغاز تعتمد على الشبكة مع أسهم قابلة للتدوير.
- **مستويات متعددة الصعوبة:** 4 فئات صعوبة (سهل، متوسط، صعب، خبير) مع 50 مستوى لكل منها.
- **نظام حياة وعملات:** إدارة الحياة والعملات المعدنية داخل اللعبة.
- **نظام تلميحات:** استخدم العملات المعدنية للحصول على تلميحات.
- **إعلانات مكافأة:** مدمجة مع Google Mobile Ads لاستعادة الحياة.
- **تصميم أنيق:** واجهة مستخدم بسيطة وحديثة مع تأثيرات نيون وجزيئات.
- **تأثيرات صوتية وارتدادية:** تجربة لعب غامرة.
- **شاشات كاملة:** شاشات البداية، الرئيسية، اختيار الصعوبة، اختيار المستوى، اللعب، قائمة الإيقاف المؤقت، شاشة الفوز، نافذة الخسارة المنبثقة، الإعدادات، والمتجر.
- **تحسين الأداء:** أداء سلس بمعدل 60 إطارًا في الثانية على أجهزة Android.

## التثبيت والتشغيل

1. استنسخ المستودع:
   ```bash
   git clone [URL_المستودع_هنا]
   ```
2. انتقل إلى دليل المشروع:
   ```bash
   cd arrow_escape_puzzle
   ```
3. احصل على التبعيات:
   ```bash
   flutter pub get
   ```
4. قم بتشغيل التطبيق:
   ```bash
   flutter run
   ```
